2) Тема проекта
"Разработка системы мониторинга и удаленного управления гаражными воротами"
3) Задачи
- Эмуляция GPIO на Linux (VM): чтение сигналов с пинов (клавиатура/генератор случайных чисел);
- Обработка статусов двери: 1 — закрыта, 2 — закрывается, 3 — открывается, 4 - открыта;
- Регистрация попыток открытия двери вручную (допустимая попытка при выключенной блокировке двери, недопустимая попытка при включенной блокировке двери)
- Включение и отключение механизма защиты/блокировки от несанкционированного доступа
- REST API (FastAPI): отдача текущего статуса Android-клиенту, приём команд управления от клиента;
- Логирование: запись всех изменений состояния двери с временными метками на сервере;
- Android-приложение: отображение статуса двери, журнал событий, кнопки управления статусом двери.
4) Ожидаемый результат
 (MVP) — работающий прототип, объединяющий Linux-сервер (эмулятор Raspberry Pi) и Android-приложение.
 Сервер эмулирует чтение GPIO, обрабатывает состояния двери, ведет журнал событий и имеет связь с клиентом.
 Мобильное приложение отображает статус двери в реальном времени, показывает журнал изменений и позволяет удаленно управлять дверью.
